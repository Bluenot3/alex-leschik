# zen-foil (pointer)

The skill lives at `skills/zen-foil/` in this repository. Paths below are relative to it.

1. Read `skills/zen-foil/AGENTS.md`. It is the whole contract, tiered by what you can do.
2. Write tags with `node skills/zen-foil/scripts/replicate.mjs tag <scene> --<param> <value>` (`list` and `show <scene>` print the options).
3. Check with `node skills/zen-foil/scripts/verify.mjs <files>`. Apply every `fix:` line and run it again until it prints `OK`.
4. New scenes or engine changes: follow `skills/zen-foil/SKILL.md`, sections 4 and 5.

`zen-portfolio-animation-standard` (if present) bundles the raw portfolio source as a reference. Use it to study or change the engine, not to reproduce a plate the kit already draws.
