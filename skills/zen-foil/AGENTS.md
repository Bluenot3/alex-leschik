# zen-foil: brief for coding agents

This file is the whole contract for any agent: Codex, Claude, Cursor, Copilot, Gemini, Lovable or a small local model. Read the five lines below, then only the tier you need. `manifest.json` holds the same contract as data.

## The contract in five lines

1. **Load once:** `<script type="module" src="https://cdn.jsdelivr.net/gh/Bluenot3/alex-leschik@2285a08ee32e5cec72aff9ef30dbfd296e44dfb5/skills/zen-foil/dist/zen-foil.js"></script>`, one URL per page, pinned to a commit.
2. **Write tags:** `<zen-foil scene="…" attribute="…"></zen-foil>`. Every option is a plain HTML attribute. Close the tag; never self-close it in HTML.
3. **Only what's listed exists.** Scene ids and attributes come from `manifest.json` (or the table below). Anything else is silently ignored.
4. **Check, then fix:** run `node skills/zen-foil/scripts/verify.mjs <files>` (or `ZenFoil.check()` in the browser console). Apply each `fix:` line and run it again until it prints `OK`.
5. **Never invent:** no made-up figures, partners, dates or credentials. Delete the attribute instead. ZEN marks (`zen`, `bgc`, `near`) are for ZEN AI Co. work only.

Fill-in rules:

- `accent`: one brand colour as `#rrggbb`. `theme`: `plate` (dark, default), `paper` (light) or `clear` (ink only). The `field` background uses `variant="dark|light"`, not `theme`.
- `points` and `origin` are **lon,lat** (longitude first): Washington, D.C. is `-77.04,38.91`, London is `-0.13,51.51`.
- `mark`: `/path/to/logo.svg`, an image URL, SVG path data, or `none`. Never a ZEN mark for another brand.
- `images`: comma-separated URLs on the same site (or served with CORS).
- Real headings stay in the DOM next to the plate. The plate is the visual, not the text.
- A whole page: one hero plate, at most ~8 plates on screen, and optionally one background, `<zen-foil scene="field" fixed variant="dark" density="0.2"></zen-foil>`, as the first child of `<body>`.

## Tier 2: agents with a terminal

Don't write markup by hand. Let the scripts write it and check it:

```bash
node skills/zen-foil/scripts/replicate.mjs list                    # every scene, one line each
node skills/zen-foil/scripts/replicate.mjs show globe              # params, types, ranges, example, template
node skills/zen-foil/scripts/replicate.mjs tag globe --headline "OUR REACH" --origin "-74.00,40.71" --points "-0.13,51.51; 2.35,48.86" --mark /logo.svg
node skills/zen-foil/scripts/replicate.mjs tag --json '{"scene":"seal","headline":"ACME LABS","mark":"/logo.svg"}'
node skills/zen-foil/scripts/replicate.mjs tag network --nodes "PLANNER, CODER" --react   # <ZenFoil> for React
node skills/zen-foil/scripts/replicate.mjs page seal --headline "ACME LABS" --heading "Acme Labs" --out public/seal.html
node skills/zen-foil/scripts/replicate.mjs page seal … --inline    # bundle inlined, for sandboxes that block CDNs
node skills/zen-foil/scripts/install.mjs .                         # React, Next, Vue, Svelte, Astro: vendors bundle + types
node skills/zen-foil/scripts/verify.mjs src index.html             # run after every edit until it prints OK
```

The loop is **replicate, paste, verify, fix**. `replicate.mjs` refuses bad input and prints the fix. `verify.mjs` exits with 1 while anything is wrong, so you can't miss it.

In the browser console, the same contract is live:

```js
ZenFoil.describe("globe")                                   // params, types, ranges, example
ZenFoil.snippet("seal", { headline: "ACME LABS" }, { accent: "#ff6a00" })
ZenFoil.check()                                             // every plate on this page, with fixes
document.querySelector("zen-foil").replay()                 // play the minting intro again
```

## What agents get wrong (and the fix)

| Symptom | Cause | Fix |
|---|---|---|
| Nothing renders, console 404 | The CDN URL points at a branch that doesn't contain the skill | Use the pinned URL from `release.json` (`replicate.mjs cdn` prints the tag) |
| Plate stays a flat gradient | Two different `zen-foil.js` URLs on one page, or the scene id is misspelled | Load one URL; run `verify.mjs` |
| Text missing on the plate | `title=`, `text=`, `subtitle=` | `headline=`, `subline=` (`title` is the HTML tooltip) |
| Logo missing | `logo=`, `icon=` | `mark="/logo.svg"` |
| Colour ignored | `color=` | `accent="#hex"` |
| Map points in the sea | lat,lon order | lon,lat (longitude first) |
| Field background ignores `theme` | `field` draws its own ground | `variant="dark"` or `variant="light"` |
| Everything after the plate vanishes | `<zen-foil … />` in HTML | `<zen-foil …></zen-foil>` |
| React 18: styles don't apply | `className` on the raw element | `class`, or the `<ZenFoil>` wrapper |
| ZEN copy on a client site | Brand params left at defaults | Set every `[brand]` param that `replicate.mjs show <scene>` lists |
| Edits to `dist/zen-foil.js` vanish | `dist/` is generated | Edit `src/`, then `node scripts/build.mjs` |
